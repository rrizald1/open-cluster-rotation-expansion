01 · Overview

Rotation beyond the cluster core

We investigate rotation, expansion, and contraction across open-cluster cores and tidal tails using radial-velocity and proper-motion information.

The analysis considers three membership schemes—Core + Tails, Core-only, and Tails-only—to compare the kinematic signatures across different cluster components.

02A · Rotation

Distinct rotation axes in core and tails

Position-angle scans identify the orientation associated with the maximum radial-velocity difference between opposite sides of the cluster. Rotation is then quantified from the corrected radial velocity as a function of the distance from the inferred rotation axis.

Proper-motion analysis provides an independent view through the tangential component, μT.

03 · Methods

Analysis overview

RV

Rotation

Scan position angles to identify the maximum velocity difference between opposite sides, defining the rotation-axis orientation. The rotation component is obtained from the slope of RVcorrected versus XR.

PM

Rotation

The tangential proper-motion component μT is examined as a function of radius to trace rotation.

PM

Expansion / Contraction

The radial proper-motion component μR is examined as a function of radius to identify expansion or contraction.

SAMPLE

Membership schemes

Results are analyzed and compared for Core + Tails, Core-only, and Tails-only membership schemes.
